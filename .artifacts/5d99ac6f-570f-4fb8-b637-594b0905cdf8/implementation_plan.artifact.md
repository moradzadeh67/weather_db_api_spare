# برنامه پیاده‌سازی پروژه آب‌وهوا (Weather SSD/SPARC Project)

پروژه آب‌وهوا با استفاده از روش **SSD (Specification-Driven Development)** بر اساس چک‌لیست و قوانین `AGENTS.md` پیاده‌سازی خواهد شد. برای مدیریت وضعیت از قابلیت‌های بومی فلاتر نظیر `ChangeNotifier` و `ListenableBuilder` استفاده خواهیم کرد که ۱۰۰٪ با قانون **Clean Dependencies** (عدم وجود وابستگی‌های اضافی) سازگار است.

---

## 🎨 طرح هندسی و جزئیات رابط کاربری مینیمال و حرفه‌ای (UI Design)

طراحی این اپلیکیشن با الهام از طراحی‌های مدرن و مینیمال (مثل Apple Weather و Material 3) به صورت فوق‌العاده چشم‌نواز با تم داینامیک خواهد بود.

### ۱. پالت رنگی (Color Palette)
- **رنگ‌های زنده آب‌وهوای صاف/آفتابی:** طیف آبی ملایم تا طلایی گرم (`#4A90E2` تا `#F5A623`)
- **رنگ‌های زنده آب‌وهوای ابری/بارانی:** خاکستری-آبی تیره با بافت مات (`#3C4B64` تا `#708090`)
- **رنگ‌های وضعیت آفلاین/ذخیره شده:** خاکستری مینیمال با افکت مه‌آلود جهت اعلام بصری حالت کش (Cached)
- **رنگ متن‌ها:** سفید صدفی (`#F8F9FA`) برای خوانایی عالی در تمام پس‌زمینه‌ها

### ۲. ساختار و چیدمان بصری صفحه اصلی (Visual Layout)
رابط کاربری به صورت کارت‌های شناور با گوشه‌های گرد نرم (Rounded Corner Cards) و فضاهای خالی متعادل طراحی می‌شود:

```text
+---------------------------------------------------+
|  [!] حالت آفلاین / نمایش داده‌های ذخیره شده          |  <-- هدر هشدار آفلاین (فقط در صورت عدم اتصال)
+---------------------------------------------------+
|                  TEHRAN, IRAN                     |  <-- نام شهر با فونت خوانا و بافاصله
|                 Last update: 12:45                |  <-- زمان به‌روزرسانی محلی با رنگ ملایم
|                                                   |
|                      ☁️                           |  <-- آیکون بزرگ متناسب با وضعیت آب‌وهوا
|                     28°C                          |  <-- دمای بزرگ و برجسته با افکت سایه ملایم
|                 Partly Cloudy                     |  <-- شرح وضعیت آب‌وهوا
|                                                   |
|             [ ↻ Update Weather ]                  |  <-- دکمه به‌روزرسانی شیک با آیکون لودینگ چرخان
+---------------------------------------------------+
|  📊 اطلاعات تکمیلی (کارت‌های گرید دو ستونه)          |
|                                                   |
|  +---------------------+   +-------------------+  |
|  | 💧 Humidity         |   | 💨 Wind Speed     |  |
|  |   15%               |   |   12.9 km/h       |  |
|  +---------------------+   +-------------------+  |
|  | 🎈 Pressure         |   | 🌡️ Real Feel       |  |
|  |   888 hPa           |   |   30°C            |  |
|  +---------------------+   +-------------------+  |
+---------------------------------------------------+
```

## بررسی پیش‌نیازها و سرویس‌های API
- سرویس **Open-Meteo API** (رایگان و بدون نیاز به کلید دسترسی) بررسی شد و کاملاً فعال و پاسخگو است.
- پکیج‌های `http: ^1.6.0` و `path_provider: ^2.1.6` با موفقیت در حالت آفلاین روی پروژه اعمال و نصب شدند (`flutter pub get --offline` با موفقیت اجرا شد).

## تغییرات پیشنهادی مرحله به مرحله (طبق چک‌لیست AGENTS.md)

### ۱. آماده‌سازی ساختار پوشه‌ها
ساختار پروژه به صورت تمیز و استاندارد ایجاد خواهد شد:
- `lib/models/` برای مدل داده
- `lib/services/` برای سرویس‌های API و ذخیره‌سازی محلی
- `lib/state/` برای مدیریت وضعیت برنامه
- `lib/pages/` برای صفحات رابط کاربری

### ۲. مدل داده (Model)
